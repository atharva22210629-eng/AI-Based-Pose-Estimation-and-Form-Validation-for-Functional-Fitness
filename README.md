# 💪 AI-Based Pose Estimation and Form Validation for Functional Fitness

## 📌 Overview

This project presents a **real-time fitness form correction system** designed for functional training environments such as HYROX. The system leverages **computer vision and pose estimation techniques** to analyze human body movements and provide instant feedback on exercise form.

Using a webcam, the application detects key body landmarks and evaluates posture during exercises like squats and planks. Based on joint angles and movement patterns, it classifies the form as correct or incorrect and guides the user with actionable feedback.

---

## 🎯 Problem Statement

Improper exercise form can lead to injuries and reduced performance. Most individuals do not have access to personal trainers, making it difficult to maintain correct posture during workouts.

This project aims to solve this problem by creating an **AI-powered virtual fitness assistant** that provides **real-time posture correction and rep tracking**.

---

## 🚀 Features

* 📷 Real-time pose detection using webcam
* 🧠 AI-based posture analysis
* ✅ Correct vs Incorrect form detection
* 🔢 Automatic repetition counting
* 💬 Instant feedback (e.g., *“Go Lower”, “Keep Back Straight”*)
* ⚡ Lightweight and runs in real-time

---

## 🛠️ Tech Stack

* **Python**
* **MediaPipe (Pose Estimation)**
* **OpenCV (Video Processing)**
* **NumPy**

---

## ⚙️ How It Works

1. Captures live video using webcam
2. Detects body landmarks using MediaPipe
3. Calculates joint angles (knees, hips, shoulders)
4. Applies rule-based logic to evaluate posture
5. Displays feedback and counts repetitions
